# 125A Chopperator / P001
Audio insert FX, 125A Systems, Windows x64 VST3. No MIDI, sample repeats, pitch changes, additional effects or curve drawing. Stereo shared gain, zero latency intended. For held powerchords after amp simulation, pads, bass, vocals and FX.
Owner-approved controls: START/MID/END binary notes 1/1..1/64; LENGTH 1/4, 1/2 and each whole bar 1–64; movable MID POSITION; CURVE; SHAPE rectangle (width produces pulse), saw up/down, triangle, sine; WIDTH, ATTACK, RELEASE, MIX; automatable ACTIVE; ONE SHOT/LOOP. Local musical time from tempo/meter, not absolute song position. ACTIVE rising edge starts; off or completed one-shot returns dry; held active does not retrigger; loop repeats trajectory without oscillator phase reset. DAW global bypass separate. Large START/MID/END/LENGTH, smaller secondary controls; impulse display; final GUI open.
## Engineering proposals for initial core
Defaults inactive, two bars, 1/2→1/16→1/2, position 50%, linear, width 50%, attack 2%, release 5%, mix 100%, rectangle, one-shot. MID position 1–99% to avoid degenerate segments. Shapes occupy width fraction of cycle. Attack/release full-scale gain slew as fraction of instantaneous cycle, minimum 0.5 ms (provisional; measure aliasing and sonic behavior); inactive/completed ramp to dry with minimum slew. Mix zero exact dry, no boost. Timing and waveform controls intentionally not neutral at normalized zero. Live tempo/meter; invalid clock retains previous. Host automation, live control smoothing, state and bypass still pending.
## Mathematical derivation
One scalar gain per sample, shared across stereo. No imported DSP dependency, no buffers/locks/allocations in audio tick. Note denominator d gives d*BPM/240 Hz. Local progress dx=BPM/(60*sampleRate*quartersPerBar*bars). Each segment rate a+(b-a)*u^k, k=2^(2*CURVE); integral a*u+(b-a)*u^(k+1)/(k+1), scaled by segment length and quartersPerBar*bars/4 for cycles. Integrate through loop without phase reset. Mathematically derived; edge smoothing duration estimated pending measurement. No assumed oversampling benefit. C++23 core; VS2022/GCC targets; SDK version/dialect compatibility to be pinned and checked separately.
